# NormGraph

Graph system mapping normative cross-references in the Italian code of criminal procedure.

Builds a graph of articles and their reciprocal references from the text of the *codice di procedura penale*, to study the structure of normative interconnections.

**Status: experimental.**

## Documentation

Full documentation of the graph system: [README_GRAPH_SYSTEM.md](README_GRAPH_SYSTEM.md)

## Quick start

```bash
pip install -r requirements.txt
python examples/complete_workflow.py
```
